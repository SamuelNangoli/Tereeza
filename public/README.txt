TEREEZA WEBSITE

REDESIGN — 31 OCTOBER 2026
Four pages redesigned using zeyraglow.com as a layout and typography reference.
Tereeza's emerald, midnight and warm amber palette is preserved in both themes.
Manrope headings and Inter body text use Google Fonts and matching offline fallbacks.
Services now use larger image cards and category filters. See ASSET-NOTES.md
for image provenance and the plan for adding the user's original service posters.

OPEN THE WEBSITE
Extract the complete ZIP and open index.html in a current browser.
Keep all four HTML pages, favicon.svg and the complete assets folder together.
No installation, server or build command is required for the downloaded website.

PAGES
index.html — Landing page and Let's fix it WhatsApp inquiry form.
services.html — OS, networking, hardware, device setup, and software development and maintenance services.
how-it-works.html — The steps for getting tech help.
meet-tereeza.html — Meet Samuel Nangoli and the team, including Matthew Mukasa.
Team buttons select a service and carry a team-member preference into the inquiry.

INQUIRIES
Service buttons return to the landing page and select the chosen service.
Enter the device and issue, then choose Continue on WhatsApp.
Review and send the prepared message in WhatsApp. Nothing is sent automatically.
Internet access and WhatsApp access are required to contact Tereeza.

APPEARANCE
Use the sun/moon button to switch between light and dark mode.

when browser storage is available. The choice applies across all four pages.

PUBLISH OR EDIT
Upload all four HTML pages, favicon.svg and the complete assets folder to a static host.
Shared appearance is in assets/site.css. Shared behavior is in assets/site.js.
The original supplied logos and portrait are also in assets.
